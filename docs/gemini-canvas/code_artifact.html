⚠️
คำเตือนทางการแพทย์สำคัญพิเศษสำหรับผู้ป่วยโรคไตทุกระยะ:
  • ห้ามรับประทานมะเฟืองเด็ดขาด: มีสารพิษ Caramboxin และออกซาเลตสูงมาก ไตเสื่อมไม่สามารถขับได้ อาจชัก โคม่า หรือเป็นอันตรายถึงชีวิต
  • ระวังเกลือ/ซีอิ๊ว "ลดโซเดียม": มักทดแทนด้วย "โพแทสเซียมคลอไรด์" ซึ่งทำให้โพแทสเซียมในเลือดสูงวิกฤต หัวใจหยุดเต้นเฉียบพลันได้ ให้ใช้ซีอิ๊วขาวธรรมดาแต่ตวงช้อนชาแทน
  • คำว่า "ทานได้ (สีเขียว)" : หมายถึงปลอดภัยจากแร่ธาตุส่วนเกิน แต่ต้องรับประทานในปริมาณที่พอดีตามพลังงานที่ร่างกายต้องการ ไม่ควรทานอย่างใดอย่างหนึ่งมากเกินไป

สารอาหารสำคัญที่เกี่ยวข้อง:
💡 วิธีรับประทานและการปรุงอย่างปลอดภัย

แหล่งข้อมูลและแนวทางเวชปฏิบัติอ้างอิง:

เกณฑ์โภชนาการสำหรับโรคไตแต่ละระยะ

กฎ 3 แร่ธาตุ และความต่างของระยะโรค

ระยะ 1-2 (eGFR ≥ 60): ชะลอความเสื่อม

ไตยังกรองของเสียได้ดี ยังไม่ต้องงดผักผลไม้หรือไข่แดงอย่างเข้มงวด แต่ให้เน้นลดเค็ม (โซเดียม < 2,000 มก./วัน) และควบคุมโรคต้นเหตุ เช่น เบาหวานและความดันโลหิต

ระยะ 3 (eGFR 30-59): เริ่มเฝ้าระวังแร่ธาตุ

เริ่มจำกัดโปรตีนเหลือ 0.6 - 0.8 กรัม/กก./วัน ตรวจเลือดติดตามระดับโพแทสเซียมและฟอสฟอรัสสม่ำเสมอ เริ่มเลี่ยงเครื่องในและเนื้อแปรรูป

ระยะ 4-5 ก่อนฟอก (eGFR < 30): เข้มงวดสูงสุด

จำกัดโปรตีนต่ำ (Low-protein diet) เพื่อลดของเสียคั่ง หลีกเลี่ยงผักผลไม้โพแทสเซียมสูงเด็ดขาด เพราะเสี่ยงหัวใจเต้นผิดจังหวะ และระวังอาการบวมน้ำ

ระยะฟอกไต / ล้างไต (Dialysis): ต้องเพิ่มโปรตีน!

ขั้นตอนการฟอกเลือดหรือล้างไตจะสูญเสียโปรตีนไปกับกระบวนการ ผู้ป่วยจึงต้องทานโปรตีนคุณภาพสูง (ไข่ขาว, ปลา) เพิ่มขึ้นเป็น 1.2 - 1.4 กรัม/กก./วัน แต่ยังต้องคุมฟอสฟอรัสและน้ำอย่างเคร่งครัด

กินอะไรได้บ้าง (Food Safety Checker) • สมาคมโรคไตแห่งประเทศไทย

ข้อจำกัดความรับผิดชอบ: ข้อมูลจัดทำขึ้นเพื่อการศึกษาโภชนาการเบื้องต้น ไม่สามารถทดแทนการวินิจฉัย การสั่งจ่ายยา หรือคำแนะนำเฉพาะบุคคลจากแพทย์ผู้เชี่ยวชาญหรือนักกำหนดอาหารวิชาชีพได้

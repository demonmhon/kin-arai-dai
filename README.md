# Kin Arai Dai (กินอะไรได้บ้าง) 🥗

**กินอะไรได้บ้าง** — เครื่องมือเว็บแอปพลิเคชันสำหรับช่วยให้ข้อมูลเบื้องต้นเกี่ยวกับอาหารและวัตถุดิบประกอบการดูแลตนเองตามอาการป่วย/โรคประจำตัว เพื่อเป็นแนวทางประกอบการตัดสินใจในชีวิตประจำวัน โดยเริ่มต้นโฟกัสที่ **โรคไตเรื้อรัง (Chronic Kidney Disease - CKD)** ในแต่ละระยะ พร้อมสถาปัตยกรรมที่ออกแบบมาเพื่อขยายสู่โรคอื่นๆ ในอนาคต

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Key Features)

- 🩺 **ประเมินเฉพาะเจาะจงตามระยะของโรคไต (CKD Stage Aware)**
  - รองรับการแบ่งระยะ 4 ระดับ: **ระยะ 1-2** (eGFR ≥ 60), **ระยะ 3** (eGFR 30-59), **ระยะ 4-5 ก่อนฟอก** (eGFR < 30), และ **ระยะฟอกเลือด/ล้างไต (Dialysis)**
  - เลือกระยะผ่าน **Popup Modal** เพื่อให้หน้าจอหลักสะอาดตาและโฟกัสกับข้อมูลอาหาร
  - ผลลัพธ์ระดับสีและคำแนะนำของอาหารแต่ละชนิดจะปรับเปลี่ยนตามระยะที่เลือกแบบไดนามิก (เช่น กล้วยหรือข้าวกล้องอาจเป็นสีเหลืองในระยะแรก แต่เป็นสีแดงในระยะ 4-5 ส่วนไข่ขาวต้องทานเพิ่มในระยะฟอกไต)

- 🚦 **ระบบ 3 สี เข้าใจง่าย (Traffic Light System)**
  - 🟢 **สีเขียว (ทานได้)**: ปลอดภัยจากแร่ธาตุส่วนเกินในระยะนั้นๆ (รับประทานในปริมาณที่พอดี)
  - 🟡 **สีเหลือง (คุมปริมาณ)**: ทานแต่น้อย จำกัดปริมาณ ไม่ถึงกับต้องอด
  - 🔴 **สีแดง (ควรหลีกเลี่ยง)**: แร่ธาตุสูงจัด มีสารพิษ หรือเสี่ยงต่อภาวะแทรกซ้อน

- 🛍️ **แถบตัวกรองสไตล์ E-Commerce (Sidebar Filter)**
  - แถบตัวกรองด้านข้างแบบ Sticky รวมการกรองตามเกณฑ์สีความปลอดภัยและหมวดหมู่อาหาร
  - แสดงตัวนับจำนวนรายการอาหารที่ตรงกับแต่ละเงื่อนไขแบบเรียลไทม์
  - แถบสรุปตัวกรองที่เลือกอยู่ (Active Filter Badges) สามารถคลิกปลดตัวกรองทีละรายการได้
  - รองรับหน้าจอมือถือด้วยปุ่ม **ตัวกรอง & เกณฑ์สี** ที่สไลด์ออกมาเป็น Drawer

- 🔍 **ค้นหาอาหารและหมวดหมู่อัจฉริยะ (Smart Food Search)**
  - ค้นหาได้ทั้งชื่ออาหารตรงๆ วัตถุดิบ หรือพิมพ์คำกว้างๆ เช่น `"ผลไม้"`, `"ผัก"`, `"ไข่ขาว"`, `"เครื่องปรุง"`, `"วุ้นเส้น"`
  - ปุ่มค้นหาด่วน (Quick Suggestion Tags) ใต้ช่องค้นหา

- 📋 **ข้อมูลเชิงลึกและแหล่งอ้างอิงประกอบ (Food Detail Modal)**
  - กลไกทางการแพทย์: เหตุผลที่อาหารจัดอยู่ในเกณฑ์นั้นๆ และผลกระทบต่อไต
  - สารอาหารสำคัญที่เกี่ยวข้อง (เช่น โพแทสเซียม, ฟอสฟอรัส, โซเดียม, โปรตีน)
  - วิธีรับประทานและการปรุงอาหารอย่างปลอดภัย
  - ลิงก์แหล่งข้อมูลประกอบจากหน่วยงานที่น่าเชื่อถือ เช่น สมาคมโรคไตแห่งประเทศไทย, รพ.รามาธิบดี, รพ.ศิริราช, American Kidney Fund

- 📸 **ภาพถ่ายจริงสัญญาอนุญาต Creative Commons (CC Images)**
  - หมวดผลไม้แสดงภาพถ่ายจริงที่ได้รับอนุญาตแบบ Creative Commons (CC / CC0 License) พร้อมระบุที่มาของภาพอย่างถูกต้อง
  - รายการอาหารที่ยังไม่มีรูป จะแสดงเป็นกล่องสี Placeholder เปล่าๆ ที่ดูสะอาดตา

- ⚠️ **กล่องเตือนภัยทางการแพทย์สำคัญ (Medical Warnings)**
  - เตือนภัยการห้ามรับประทาน **มะเฟือง** เด็ดขาด (สารพิษ Caramboxin และออกซาเลตสูง)
  - เตือนภัยกับดัก **เกลือ/ซีอิ๊วลดโซเดียม** ที่มักใส่โพแทสเซียมคลอไรด์ทดแทน

- 🌐 **สถาปัตยกรรมพร้อมรองรับหลายโรค (Multi-Disease Architecture)**
  - ระบบเตรียมพร้อมสำหรับการเพิ่มโรคประจำตัวอื่นๆ เช่น โรคเบาหวาน, โรคเกาต์, โรคความดันโลหิตสูง และกรดไหลย้อน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **UI Component Library**: [Mantine UI (v7)](https://mantine.dev/)
  - `@mantine/core`
  - `@mantine/hooks`
  - `@tabler/icons-react`
  - `postcss-preset-mantine`
- **Typography**: [Prompt](https://fonts.google.com/specimen/Prompt) (Google Fonts)
- **Styling**: Vanilla CSS + PostCSS Modules

## 🚀 การติดตั้งและรันโปรเจกต์ (Getting Started)

### ความต้องการพื้นฐาน
- **Node.js**: เวอร์ชัน 18 ขึ้นไป (แนะนำ v20 หรือ v22)
- **npm** หรือ **pnpm** หรือ **yarn**

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รัน Dev Server สำหรับทดสอบในเครื่อง
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:5173`

### 3. ตรวจสอบ Type & Build สำหรับ Production
```bash
npm run build
```

### 4. พรีวิว Production Build
```bash
npm run preview
```
